# 🌟 Seja Bem-vindo 

Sou o desenvolvedor por trás do projeto [Gleam-BR](https://gleam.dev.br). **A comunidade brasileira do [Gleam-Lang](https://gleam.run/).**

Somos uma iniciativa dedicada à produção, curadoria e desenvolvimento de sistemas de missão crítica, focada na clareza da linguagem **Gleam** e na resiliência do ecossistema **BEAM (Erlang/OTP)**. <img width="20" height="20" alt="lúcia" src="https://github.com/gleam-br/.github/blob/main/profile/lucy_emoji_transparent.png" /> 

Somos um espaço **laico, livre e colaborativo**, para saber mais [clique aqui](https://github.com/gleam-br).

## 🏗️ Estrutura

Nossa atuação é dividida entre o desenvolvimento na comunidade e atuação empresarial de ponta:

* **[gleam.dev.br](https://gleam.dev.br):** Nosso braço **sem fins lucrativos**. Um espaço de inovação e software livre focado exclusivamente em Gleam, Erlang/OTP e JavaScript. É aqui que nascem as bibliotecas e ferramentas que sustentam o ecossistema todo.
* **[gleam-lang.com.br](https://gleam-lang.com.br):** Nossa operação **comercial**. Focada em soluções empresariais robustas, integrando Gleam e Erlang à solidez (legado) do ecossistema Java e à onipresença (hype) do JavaScript.
* **[fvideen.com.br](https://fvideen.com.br):** **Freunde Von Ideen**, nossa consultoria de sistemas e desenvolvimento, que provê a governança e a experiência de engenharia por trás de todas as iniciativas.

## 📖 Nossa Filosofia: A Lucidez Tecnológica

Nós somos guiados por um documento muito especial que dita o tom de como interagimos: **Nosso Manifesto**. Segue um breve resumo:

1. **A Autonomia é Absoluta:** Você é livre para criar e usar as ferramentas que quiser (incluindo Inteligência Artificial e tradutores automáticos) para expressar seu código e suas ideias.
2. **Zero Meritocracia Tóxica:** Ninguém aqui é melhor que ninguém. Dúvidas não geram "broncas", geram acolhimento. A sabedoria precede o algoritmo.
3. **O Coração Alinhado à Razão:** Tudo o que fazemos visa o bem comum. Não gastamos energia em discussões vazias; gastamos energia criando.

## 🛠️ O Que Nós Construímos

Nosso foco é criar bibliotecas, *scaffoldings* e ferramentas que facilitem a vida de quem desenvolve em Gleam, abraçando os *targets* Erlang/JS e NIFs Rust.

### 🛫 Bibliotecas

- [create-vite-lustre](https://github.com/gleam-br/create-vite-lustre): 📦 `npm create vite-lustre` tool.
- [vite-plugin-gleam](https://github.com/gleam-br/vite-plugin-gleam): ✨ [Vite](https://vite.dev/) plugin p/ gleam.
- [bun-plugin-gleam](https://github.com/gleam-br/bun-plugin-gleam): 🥯 [Bun](https://bun.com/) plugin p/ gleam.
- [gbr_disk_log](https://github.com/gleam-br/gbr_disk_log): 💽 Erlang Disk Log Gleam Wrapper
- [gbr_shared](https://github.com/gleam-br/gbr_shared): 👯 Shared library p/ gleam target [js](https://developer.mozilla.org/en-US/docs/Web/JavaScript) e [erl](https://erlang.org).
- [gbr_js](https://github.com/gleam-br/gbr_js): 🎃 Javascript library p/ gleam, somente target [js](https://developer.mozilla.org/en-US/docs/Web/JavaScript).
- [gbr_erl](https://github.com/gleam-br/gbr_erl): 🍀 Erlang library p/ gleam, somente target [erl](https://erlang.org).
- [gbr_gh](https://github.com/gleam-br/gbr_gh): 🔮 Github Rest API client.
- [gbr_json](https://github.com/gleam-br/gbr_json): 📃 JSON/JSON-RPC/JSON-Schema tipos e funções.
- [gbr_mcp](https://github.com/gleam-br/gbr_mcp): 🧠 Model Context Protocol Server/Client tipos e funções.
- [gbr_msal](https://github.com/gleam-br/gbr_msal): 🛂 Gleam MS Authorization integração com o [MS authorization library](https://learn.microsoft.com/pt-br/entra/identity-platform/msal-overview).
- [gbr_md](https://github.com/gleam-br/gbr_md): Ⓜ️ Gleam Markdown para lustre, `gbr_ui` (integração em breve...)
- [gbr_ui](https://github.com/gleam-br/gbr_ui): 📺 Gleam + [Lustre](https://lustre.build) + Tailwind + Admin desenvolvendo componentes visuais.
- [gbr_ui_router](https://github.com/gleam-br/gbr_ui_router): 📡 Gleam JS/SPA router usa a biblioteca [modem](https://github.com/hayleigh-dot-dev/modem).

Sinta-se livre para explorar nossos repositórios, clonar, testar e, claro, quebrar algumas coisas no processo (faz parte do aprendizado!).

## 🤝 Como Fazer Parte

A [Gleam-BR](https://github.com/gleam-br) é construída por pessoas e para pessoas. Se você quer contribuir, não existe barreira, seja bem-vindo 🤗:

* **Não sabe falar português?** Fale na sua língua nativa! Nós fazemos o esforço de entender e traduzir juntos.
* **Usou IA para escrever o código ou a PR?** Incrível! Ferramentas existem para expandir nossa mente, e nós celebramos a sua engenhosidade.
* **Achou um bug ou teve uma ideia?** Abra uma *Issue* ou participe das nossas *Discussions*. Não se preocupe com formalidades excessivas, foque apenas na intenção sincera de compartilhar.
